주제: Free Time / Programming Problems

오늘 말한 핵심 내용:
- I usually solve programming problems in my free time.
- I usually solve algorithm and data structure problems.
- I’m good at reading code, but I’m not good at writing code myself.
- Graph problems are difficult for me.
- When I don’t know how to solve a problem, I use ChatGPT or search Google.
- I organize the solution in my notes.

자연스럽게 고칠 표현:
- `solve the programming problem` → `solve programming problems`
- `algorithm and data structure problem` → `algorithm and data structure problems`
- `I’m good at reading the code` → `I’m good at reading code`
- `I’m not good at typing the code myself` → `I’m not good at writing code myself`
- `I don't know the graph algorithm exactly.` → `I don’t know graph algorithms very well.`
- `search the Google` → `search Google`
- `organize the solution in my note` → `organize the solution in my notes`
- `make my solution` → `come up with a solution`

오늘의 핵심 표현:
- `be good at ~ing` — ~을 잘하다
- `be not good at ~ing` — ~을 잘하지 못하다
- `come up with a solution` — 해결책을 생각해내다
- `structure my code` — 코드를 구조화하다
- `by myself` — 스스로
- `in my free time` — 여가 시간에

오늘의 답변 구조:
`의견 → 이유 → 예시/추가 설명`

예:
> I think solving programming problems is a good way to improve coding skills.  
> Because I can learn how to structure my code and come up with solutions.  
> It also helps me practice solving problems by myself.

오늘 최종 토스 답변:
> Solving programming problems is a good way to improve coding skills because I can learn how to structure my code and come up with solutions. It also helps me practice solving problems by myself.

오늘의 재사용 문장:
> **It is a good way to improve my skills because I can learn through practice.**

이 문장은 토스에서 운동, 공부, 취미, 온라인 강의 같은 거의 모든 주제에 재사용할 수 있습니다.
